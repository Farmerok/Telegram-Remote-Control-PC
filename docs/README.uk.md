# PCGuardControl

## 📝 Вступ

Ласкаво просимо до **PCGuardControl** — інструменту для віддаленого керування своїм комп'ютером Windows через Telegram.

Бот дозволяє виконувати повсякденні дії з ПК прямо з чату: керувати живленням і звуком, працювати з файлами та застосунками, отримувати скріншоти, контролювати процеси, використовувати віддалену мишу та клавіатуру, запускати трансляцію екрана й камери та багато іншого.

Підтримується **один або кілька адміністраторів**. Наприклад, можна надати доступ кільком довіреним користувачам на одному комп'ютері.

Проєкт отримує оновлення з виправленнями, покращеннями та новими функціями.

## 📂 Керування файлами та папками

PCGuardControl дозволяє працювати з файловою системою комп'ютера без прямого доступу до робочого стола.

- **📁 Навігація по папках** — переходьте між директоріями та переглядайте їхній вміст.
- **📂 Створення папок** — створюйте нові директорії в обраному місці.
- **✏️ Перейменування** — змінюйте імена файлів і папок.
- **🔍 Перегляд вмісту** — отримуйте список файлів і папок поточної директорії.
- **📥 Завантаження на ПК** — надсилайте файли з Telegram на комп'ютер.
- **📤 Скачування з ПК** — отримуйте потрібні файли з комп'ютера в Telegram.
- **🚀 Запуск файлів** — відкривайте файли та програми з обраної директорії.
- **🗑️ Видалення** — видаляйте обрані файли та папки.
- **🔗 Завантаження за посиланням** — скачуйте файли на ПК за прямим посиланням.

## ⚠️ Важлива інформація

- Проєкт є **пропрієтарним** і не має відкритого вихідного коду.
- Функції віддаленого керування, роботи з процесами, вводом, файлами та системою можуть викликати підвищену увагу антивірусів.
- Завантажуйте програму лише з джерела, якому довіряєте.
- Не використовуйте один Telegram-токен одночасно в кількох екземплярах програми.
- Перед використанням функцій із розділу **Небезпечні функції** уважно перевіряйте обрану дію.
- Використовуйте програму лише на своєму комп'ютері або на пристроях, якими вам дозволено керувати.

### Що таке `update.exe`?

`update.exe` використовується для оновлення PCGuardControl. Він дозволяє завантажити та встановити нову версію без повного ручного перевстановлення.

### Про спрацювання антивірусів

Деякі антивіруси можуть реагувати на програми віддаленого керування через функції роботи з системою, процесами, файлами, вводом і мережею.

Якщо антивірус показує попередження:

1. переконайтеся, що файл отримано з офіційного або довіреного джерела;
2. перевірте файл доступними вам засобами;
3. додавайте його до винятків лише якщо впевнені в походженні файлу.

### 🚨 Відмова від відповідальності

Розробники не несуть відповідальності за незаконне або несанкціоноване використання програми.

Не використовуйте PCGuardControl для доступу до чужих пристроїв без дозволу, втручання в роботу чужих систем або дій, що порушують закон і права інших осіб.

## ⚙️ Налаштування скрипта

Є два способи первинного налаштування.

### Варіант 1 — автоматичний

1. Запустіть програму.
2. Якщо `settings.ini` відсутній, він буде створений автоматично.
3. Вкажіть токен Telegram-бота та ID адміністратора.

### Варіант 2 — вручну

Створіть поряд із програмою файл `settings.ini`:

```ini
[BotConfig]
token = YOUR_BOT_TOKEN
admin_list = 123456789, 987654321

[Proxy]
use_proxy = False
proxy_type = http
proxy_url = ip:port
proxy_user =
proxy_pass =
```

> 💡 Розділ `[Proxy]` необов'язковий. Якщо проксі не використовується, залиште `use_proxy = False`. За потреби програма може створити відсутні параметри автоматично.

## 🌐 Налаштування проксі

Проксі можна використовувати, якщо пряме підключення до Telegram недоступне або потрібен інший маршрут підключення.

### З логіном і паролем

```ini
[Proxy]
use_proxy = True
proxy_type = http
proxy_url = 45.67.89.10:3128
proxy_user = mylogin
proxy_pass = mypassword
```

### Без авторизації

```ini
[Proxy]
use_proxy = True
proxy_type = http
proxy_url = 45.67.89.10:3128
proxy_user =
proxy_pass =
```

Підтримувані типи:

- `http`
- `https`
- `socks5`

> ⚠️ Безкоштовні публічні проксі часто нестабільні та можуть перестати працювати в будь-який момент.

Якщо проксі недоступне під час запуску, бот робить до **3 спроб підключення**, після чого вимикає проксі й запускається через пряме з'єднання. Якщо проксі перестало працювати вже під час роботи бота, він також перемикається на пряме підключення й надсилає сповіщення в Telegram.

Налаштувати або змінити проксі можна безпосередньо в боті:

**Панель бота → Конфігурація бота → Проксі**

## 🔑 Як отримати дані для запуску

### 1. Токен Telegram-бота

1. Відкрийте [@BotFather](https://t.me/BotFather).
2. Надішліть команду `/newbot`.
3. Дотримуйтесь інструкцій Telegram.
4. Скопіюйте отриманий токен у параметр `token` файлу `settings.ini`.

Приклад формату:

```text
123456789:ABCDefghIJKLMNOPQRSTUVWXYZ
```

> Нікому не передавайте справжній токен бота. За його допомогою можна отримати доступ до керування ботом.

### 2. Telegram ID адміністратора

Отримати свій Telegram ID можна через спеціальних інформаційних ботів, наприклад `@userinfobot`.

Додайте ID до:

```ini
admin_list = 123456789
```

Для кількох адміністраторів вкажіть ID через кому:

```ini
admin_list = 123456789, 987654321
```
