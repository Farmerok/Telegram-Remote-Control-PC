# PCGuardControl

## 📝 Введение

Добро пожаловать в **PCGuardControl** — инструмент для удалённого управления своим Windows‑компьютером через Telegram.

Бот позволяет выполнять повседневные действия с ПК прямо из чата: управлять питанием и звуком, работать с файлами и приложениями, получать скриншоты, контролировать процессы, использовать удалённую мышь и клавиатуру, запускать трансляцию экрана и камеры и многое другое.

Поддерживается **один или несколько администраторов**. Например, можно предоставить доступ нескольким доверенным пользователям на одном компьютере.

Проект получает обновления с исправлениями, улучшениями и новыми функциями.

## 📂 Управление файлами и папками

PCGuardControl позволяет работать с файловой системой компьютера без прямого доступа к рабочему столу.

- **📁 Навигация по папкам** — переходите между директориями и просматривайте их содержимое.
- **📂 Создание папок** — создавайте новые директории в выбранном месте.
- **✏️ Переименование** — меняйте имена файлов и папок.
- **🔍 Просмотр содержимого** — получайте список файлов и папок текущей директории.
- **📥 Загрузка на ПК** — отправляйте файлы из Telegram на компьютер.
- **📤 Скачивание с ПК** — получайте нужные файлы с компьютера в Telegram.
- **🚀 Запуск файлов** — открывайте файлы и программы из выбранной директории.
- **🗑️ Удаление** — удаляйте выбранные файлы и папки.
- **🔗 Загрузка по ссылке** — скачивайте файлы на ПК по прямой ссылке.

## ⚠️ Важная информация

- Проект является **проприетарным** и не имеет открытого исходного кода.
- Функции удалённого управления, работы с процессами, вводом, файлами и системой могут вызывать повышенное внимание антивирусов.
- Загружайте программу только из источника, которому доверяете.
- Не используйте один Telegram‑токен одновременно в нескольких экземплярах программы.
- Перед использованием функций из раздела **Опасные функции** внимательно проверяйте выбранное действие.
- Используйте программу только на своём компьютере или на устройствах, которыми вам разрешено управлять.

### Что такое `update.exe`?

`update.exe` используется для обновления PCGuardControl. Он позволяет загрузить и установить новую версию без полной ручной переустановки.

### О срабатывании антивирусов

Некоторые антивирусы могут реагировать на программы удалённого управления из‑за функций работы с системой, процессами, файлами, вводом и сетью.

Если антивирус показывает предупреждение:

1. убедитесь, что файл получен из официального или доверенного источника;
2. проверьте файл доступными вам средствами;
3. добавляйте его в исключения только если уверены в происхождении файла.

### 🚨 Отказ от ответственности

Разработчики не несут ответственности за незаконное или несанкционированное использование программы.

Не используйте PCGuardControl для доступа к чужим устройствам без разрешения, вмешательства в работу чужих систем или действий, нарушающих закон и права других лиц.

## ⚙️ Настройка скрипта

Есть два способа первоначальной настройки.

### Вариант 1 — автоматический

1. Запустите программу.
2. Если `settings.ini` отсутствует, он будет создан автоматически.
3. Укажите токен Telegram‑бота и ID администратора.

### Вариант 2 — вручную

Создайте рядом с программой файл `settings.ini`:

```ini
[BotConfig]
token = YOUR_BOT_TOKEN
admin_list = 123456789, 987654321

[Proxy]
use_proxy = False
proxy_type = http
proxy_url = ip:port
proxy_user =
proxy_pass =
```

> 💡 Секция `[Proxy]` необязательна. Если прокси не используется, оставьте `use_proxy = False`. При необходимости программа может создать недостающие параметры автоматически.

## 🌐 Настройка прокси

Прокси может использоваться, если прямое подключение к Telegram недоступно или требуется другой маршрут подключения.

### С логином и паролем

```ini
[Proxy]
use_proxy = True
proxy_type = http
proxy_url = 45.67.89.10:3128
proxy_user = mylogin
proxy_pass = mypassword
```

### Без авторизации

```ini
[Proxy]
use_proxy = True
proxy_type = http
proxy_url = 45.67.89.10:3128
proxy_user =
proxy_pass =
```

Поддерживаемые типы:

- `http`
- `https`
- `socks5`

> ⚠️ Бесплатные публичные прокси часто нестабильны и могут перестать работать в любой момент.

Если прокси недоступен при запуске, бот делает до **3 попыток подключения**, после чего отключает прокси и запускается через прямое соединение. Если прокси перестал работать уже во время работы бота, он также переключается на прямое подключение и отправляет уведомление в Telegram.

Настроить или сменить прокси можно непосредственно в боте:

**Панель бота → Конфигурация бота → Прокси**

## 🔑 Как получить данные для запуска

### 1. Токен Telegram‑бота

1. Откройте [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot`.
3. Следуйте инструкциям Telegram.
4. Скопируйте полученный токен в параметр `token` файла `settings.ini`.

Пример формата:

```text
123456789:ABCDefghIJKLMNOPQRSTUVWXYZ
```

> Никому не передавайте настоящий токен бота. С его помощью можно получить доступ к управлению ботом.

### 2. Telegram ID администратора

Получить свой Telegram ID можно через специальных информационных ботов, например `@userinfobot`.

Добавьте ID в:

```ini
admin_list = 123456789
```

Для нескольких администраторов укажите ID через запятую:

```ini
admin_list = 123456789, 987654321
```
